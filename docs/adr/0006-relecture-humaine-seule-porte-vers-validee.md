# La relecture humaine est la seule porte vers « validée »

Les fiches sont rédigées par une chaîne d'agents, mais seule une relecture humaine peut les faire passer de brouillon à validée, et seules les fiches validées entrent dans les défis publiés. Un nombre faux, présenté comme un savoir à retenir, ruine la confiance dans le jeu : la vérification ne se délègue pas à un agent.

## Exception du prototype

Cette règle ne doit pas freiner les tests : dans le prototype, les brouillons restent jouables par défaut. Leur statut n'est visible que dans les outils de test.
